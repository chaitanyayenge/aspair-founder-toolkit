# First co-founder conversation

Use these prompts with the person you are considering working with. Keep both sets of answers and decide what remains uncertain. There is no total score.

| Topic | Person A | Person B | Next question or evidence |
| --- | --- | --- | --- |
| The problem and intended user | | | |
| What has actually been tested | | | |
| Work each person can own | | | |
| Time available each week | | | |
| Studies, employment and other commitments | | | |
| How you prefer to give feedback | | | |
| How you handle an unresolved disagreement | | | |
| A small first trial | | | |
| Time or spending boundaries | | | |
| Date and criteria for reviewing the trial | | | |

Ask for context rather than making assumptions. A profile, company logo or social link does not verify somebody’s claims. You can choose not to continue, and you do not need to promise an ownership split to have a first conversation.

From the [Aspair founder toolkit](https://www.aspair.in/startup-tools).
